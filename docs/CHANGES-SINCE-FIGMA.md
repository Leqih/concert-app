- 满员的小队显示“is full · We opened crew 2”，并自动开一个新队。

## Clips（`08`–`10`，新）
- **浏览**：
  - 全屏竖滑；
  - 用演出照片加缓慢推近的镜头模拟视频，底部有进度条；
  - 点一下暂停，双击点赞并出现爱心动画。
- **画面上的信息**：
  - 右侧：头像、点赞、评论、分享，右下角有转动的小唱片；
  - 左下：发布者名字，加位置标签“📍 场馆 · On-site / Tagged”，然后是一句文案、滚动的歌名，以及演出卡片和“Find a crew”按钮；
  - 顶部：For you / Following 切换（Following 只看 buddy 和小队成员）、静音、相机（发片段入口）。
- **评论**：所有人都能评论，去过的人名字旁标“Was there”；每条评论可以点赞，底部可以发评论。
- **发片段**：
  - 先选视频；
  - **位置必须填**：视频有定位就自动识别，没有就手动选场馆；
  - 按场馆和日期自动匹配是哪场演出；
  - 最后写一句文案。
