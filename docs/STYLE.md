# Plus One 视觉风格：Monochrome Editorial

> 简洁、时尚、克制。界面只用黑白灰，颜色只来自演出照片。本文件补充仓库里的 DESIGN.md，定义具体数值；两者冲突时以本文件为准。

## 1. 关键词

**黑白 · 留白 · 有态度的字 · 克制的动效**

参考气质：时尚电商和杂志 App。版面干净，字体有个性，界面元素自己不抢戏，让演出照片当主角。

## 2. 颜色

| 名称 | 值 | 用途 |
|---|---|---|
| Ink | `#0B0B0C` | 主文字、主按钮、选中态 |
| Paper | `#FFFFFF` | 卡片、弹窗 |
| Canvas | `#F2F2F4`（`--bg`） | 页面背景 |
| Fog | `#ECECEF`（`--card2`） | 次级按钮、输入框、胶囊 |
| Muted | `#6E6E73` | 辅助文字（浅底对比度 ≥ 4.5:1） |
| Line | `rgba(0,0,0,.07)` | 分割线、描边 |

- 不使用任何彩色（包括黄色便签、粉色、绿色在线点）。照片是唯一的彩色来源。
- emoji 只出现在有含义的标签上：Scene（🙋 Going solo 等）、贴纸。**标题里不放 emoji。**

## 3. 字体

- 标题：Inter Tight，800；正文：Inter。
- 字号层级（px）：

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| Page | 26 / 800 | 页面标题（Explore、Chats、Tickets） |
| Section | 20–22 / 800 | 区块标题（Hot this week） |
| Flow | 30 / 800 + 31 斜体 300 | ＋ 流程每一步的问题，一句话，最多两行 |
| Body | 15 / 400–600 | 正文、列表主文字 |
| Meta | 12.5 / 400 | 日期、场馆、计数 |
| Label | 11 / 700，全大写，字距 .06em | 小标签（UP NEXT、YOUR TICKETS） |

- 标志性写法「粗体 + 中间一个细斜体词」（What was *the* moment?）只用在流程标题，不滥用。
- 句子式大小写，文案短而直接。

## 4. 形状

- 圆角只用三档：**12**（缩略图、小胶囊外的小元素）、**20**（卡片、照片）、**胶囊**（所有按钮和筛选胶囊）。对应变量：`--r-md` / `--r-lg` / `--r-pill`。
- 主按钮：黑色胶囊，高 52，字号 16，字重 700。次按钮：白底 + 1.5px 黑描边的胶囊。
- 阴影只留一种：`0 10px 24px rgba(0,0,0,.08)`，仅用于浮在内容上的元素（底部按钮栏、浮层卡）。普通层次用分割线或底色区分。

## 5. 版面

- 左右边距 16；间距按 8 的倍数；区块之间 32。
- 标题居中（Chats 例外，左对齐）。
- 照片：圆角 20，底部黑色渐变，文字压在图上，白字。
- 少放说明文字：界面只留标签和数字，解释放进 ⓘ 弹窗（`infoB` → `INFO`）。

## 6. 动效

- 默认安静：弹簧感的 200–350ms 过渡，按下缩放到 .96–.97。
- 「好玩」只留给几个标志性时刻：＋ 菜单形状下落、选中后圆形展开、小队票盖章、座位圈、Find me a crew 雷达。
- 一律尊重 `prefers-reduced-motion`。

## 7. 品牌记号

- 三个形状：三圆人群（Start a crew）、带缺口和打孔线的票（List a spare）、竖版视频卡（Share a clip）。
- 票根打孔线 + 两侧半圆缺口：出现在小队票、换票相关的卡片上。

## 8. 例外：＋ 菜单的三个流程

Start a crew、List a spare 保留拼贴风格（点阵底、轻微倾斜的卡片、贴纸），这是 Plus One 的个性。但仍遵守第 2–4 条：只用黑白灰、按钮胶囊、流程标题用紧凑一行。Share a clip 按小红书发布流程做成白底页面。

## 9. 检查清单（加新页面时）

- [ ] 没有彩色、标题里没有 emoji
- [ ] 圆角只用 12 / 20 / 胶囊
- [ ] 主按钮是 52 高的黑色胶囊
- [ ] 没有解释性段落，必要说明进 ⓘ
- [ ] 字号落在第 3 节的层级里
