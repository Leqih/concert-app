# Plus One

**Never go alone. Never pay double.** A concert and festival app for finding a crew for the same show and swapping spare tickets at face value between verified fans. Design portfolio demo, English UI, real Ticketmaster show data.

- `demo/`: interactive single-file demo (current milestone M7). Build with `python3 demo/build.py`, then open `demo/dist/plusone-demo.html`.
- `deck/`: 42-slide user research deck. `research/`: research report and notes.
- `iterations/`: M1–M6 comparison. `app-expo/`: early React Native prototype.

Full handoff: see [HANDOFF.md](HANDOFF.md).
